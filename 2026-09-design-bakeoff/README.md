# AI Design Bake-Off (Sep 29, 2026)

A design hackathon at Studio IX. Teams redesigned the Cville AI Explorers website from scratch, starting only from its text content. Each team picked one lane of AI design tools, so the showcase compared *approaches* as well as results.

These materials moved here from `design-hackathon/` in the website repo; their history came with them.

| [`team-guide.md`](team-guide.md) | For team members: the challenge, lookbook, 60-minute workflow, prompts. |
| [`site-content.md`](site-content.md) | The site's text content, the only starting point for each redesign. |
| [`past-meetups.md`](past-meetups.md) | Portfolio of past meetups, used as stretch content. |
