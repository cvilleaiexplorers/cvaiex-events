# Codex native

Lane B: prompt-to-app. The team prompted Codex in the ChatGPT desktop app, with no design skill. Codex researched the community, wrote the code and generated the main artwork, and the site was hosted with Sites.

## Designs

- **[Focus](designs/focus/)** ([live site](https://cville-ai-focus.sifanye-ghost.chatgpt.site)): a dark olive page with a single lime accent, built around a glowing filament-knot artwork. The next meetup comes live from Meetup, followed by three past-meetup cards. See its [process narrative](designs/focus/process-narrative.md) and [design brief](designs/focus/design-brief.md).

  Focus is hosted by its author and won't be redeployed, so there's no `site/` folder; the showcase links to the live URL.
