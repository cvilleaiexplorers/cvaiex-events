# Journey: Blue Ridge at Dusk

The working files Impeccable produced on the way to the design, handed in with the build. Snapshot taken 2026-09-29.

| File | What it is |
|---|---|
| `PRODUCT.md` | The product brief from `/impeccable init` (audience, purpose, constraints) |
| `direction-round-all.png` | The "roll" decision page: the assigned direction (The Shadow Board), Impeccable's pick (The Wall Calendar), the category standard, and dealt challengers including the WebGL Shader Portal the team adopted |
| `direction-round.png` | The same page at a normal 1440 width |
| `direction-round-options.json` | Every card's full text: thesis, palette, risk, and verdicts on the declined challengers |
| `direction-contract.md` | The committed direction ("Blue Ridge at dusk"), including the room's above-the-fold change |
| `DESIGN.md` | The finished design system (colors, type, spacing, rules), written from the shipped code |
| `screenshots/` | Final captures: desktop 1440, laptop 1280×720, phone 390, and the dated-meetup state (`-dated`). The `-fold` files are the first screen, and the rest are full pages |

To see the dated state in the build itself, open `../site/index.html?next=2026-10-27`.

The Shader Portal quality-bar references came from the Impeccable catalog: https://impeccable.style/worlds/cards/webgl-shader-portal-hero.webp and https://impeccable.style/worlds/cards/webgl-shader-portal.webp
